TH-LoRA: Temporal Hierarchical Adaptive LoRA Memory for Lifelong Learning of LLMs

Proposes TH-LoRA, a temporal hierarchical adaptive LoRA memory for lifelong learning of LLMs. Inspired by human short-term/long-term memory consolidation, it achieves bounded parameter growth, reduced forgetting, and controllable merging; a medical-domain case study reveals that "LoRA learns distributions, not facts".
